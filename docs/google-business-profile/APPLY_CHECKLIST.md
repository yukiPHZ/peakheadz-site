# Apply checklist

- [ ] 実機のスマートフォンで LINE WORKS QR コードを読み取り、指定URL・表示名・アイコンを確認する

- [ ] ビジネス名、カテゴリ、営業時間を所有者が最終承認した
- [ ] 佐倉市・印西市・成田市へ実際に訪問できる条件を確認した
- [ ] 料金（8,800円 / 15,400円から / 22,000円から / 6,600円）を最終承認した
- [ ] サイトとGBPのサービス名、料金、地域、連絡方法が一致する
- [ ] GBP用UTM URLを設定し、canonicalにUTMを含めない
- [ ] 公開電話番号を追加しない方針を確認した
- [ ] 事例の会社名・写真・作業内容の掲載許可を確認した
- [ ] 顧客情報、非公開住所、認証情報がない
- [ ] Google管理画面で実際に適用する。今回の実装タスクでは適用しない。
