# Description

PEAKHEADZは、千葉県印西市を拠点に、佐倉市・印西市・成田市の小さい会社へ、パソコン、プリンター、Wi-Fi、PDF、電子契約、ファイル整理、業務改善を行う外部IT係です。現場で止まっていることを直すだけでなく、同じ問題が起きにくい流れや、小さな道具づくりまでを内容に応じて考えます。訪問・オンラインとも完全予約制です。対応範囲と対応できないことを確認し、必要な場合はメーカーや専門業者へ相談する条件も整理します。緊急・即日対応は保証していません。

共通地域表記: 印西市を拠点に、佐倉市・成田市を中心として訪問対応しています。その他の地域も、内容・移動時間・日程によりご相談ください。
