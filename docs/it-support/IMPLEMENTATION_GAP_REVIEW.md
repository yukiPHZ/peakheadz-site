## 指示と異なる点・技術的理由

- 市場観測は共有Market Observerへ接続済みで、現在は `configured_pending_deploy`。本番公開後の同意状態と実イベント受信を確認するまで `active` にはしない。
- 事例写真は、掲載許可がpendingのため公開ページへ載せない。加工候補は非公開レビュー用に限定した。
- QRコードのビット列デコードは、この作業環境にQR decoderがなく自動実施できなかった。リンク先文字列と元画像の目視は一致しているが、公開前にスマートフォンまたは別のQR readerで再確認する。

## 公開前の必須確認

1. 料金、キャンセル料、返信運用、LINE WORKSの表示名・アイコン。
2. 三市への実際の訪問条件。
3. 事例の会社名・写真・作業内容の掲載承諾。
4. QRコードの実機読み取り。
5. 本番でのGA4 / Market Observer実受信確認。
6. 375px / 768px / 1280px / 1440pxの人間による表示確認。
