# 1. 中心思想

## DAKEは、誰のためにあるのか

DAKEは、高機能なソフトを作ることを目的にしたブランドではない。

不動産の現場で、仕事を進めようとしているのに、ちょっとした操作や判断で止まってしまう人のためにある。

パソコンが得意ではない人。
入社したばかりで、何をどう進めればよいのか分からない人。
専門的なサービスや便利なツールの存在を知らない人。
誰かに聞かなければ、次へ進めなくなってしまう人。

そういう人が、迷わず、止まらず、自分の力で仕事を終えられるようにしたい。

## 俺の想い

俺は、現場で人が止まる場所をたくさん見てきた。

本人に能力がないわけではない。
やる気がないわけでもない。

入力方法が分からない。
計算の仕方が分からない。
どの情報を見ればよいのか分からない。
既存のソフトは機能が多すぎて、どこを触ればよいのか分からない。

ほんの小さなつまずきによって、仕事が止まる。

そのたびに、人へ聞く。
電話をする。
メールを送る。
返事を待つ。
説明する側も、説明される側も、少しずつ疲れていく。

俺が作りたいのは、その小さな「止まる」をなくす道具だ。

人が止まる場所を見つけて、そこへ先に道具と流れを置いておく。

それがDAKEの原点である。

## 誰のために作るのか

DAKEは、パソコンが得意な人だけのための道具ではない。

特に届けたいのは、次のような人だ。

- 不動産実務に慣れていない新人営業
- パソコン操作に不安がある営業や事務員
- 専門用語や複雑な設定が苦手な人
- 人に聞かず、自分で仕事を進められるようになりたい人
- 日々の小さな作業に時間と気力を奪われている人
- 本来の仕事に集中したい人

年齢や経験、パソコンスキルに関係なく、画面を見れば何をすればよいか分かる。

説明書を読まなくても使える。
迷う選択肢がない。
入力して、実行して、結果を受け取り、気持ちよく終われる。

そんな道具を作りたい。

## どうなってほしいのか

DAKEを使った人に、特別な技術者になってほしいわけではない。

少しだけ仕事が楽になってほしい。

今まで人に聞いていた作業を、自分一人で終えられるようになってほしい。

「これで合っているのかな」と不安になっていた人が、安心して次へ進めるようになってほしい。

操作方法を覚えることではなく、本来やるべき仕事に集中できるようになってほしい。

そして、小さな成功を積み重ねて、

- 「自分でもできた」
- 「もう人に聞かなくても大丈夫」
- 「仕事が少し怖くなくなった」

と思ってほしい。

DAKEが目指すのは、単なる時間短縮ではない。

作業時間を減らし、判断の負担を軽くし、人が自分の仕事を自分で進められる状態をつくることだ。

## DAKEの考え方

DAKEは、一つの道具に多くの機能を詰め込まない。

一つのアプリで、一つの仕事を終わらせる。

必要なものだけを置く。
迷うものは置かない。
余計な設定を求めない。
処理中でも、止まったように見せない。
間違えた人を責めるような表示をしない。

高機能であることより、現場で使えることを優先する。

できる人に評価される道具ではなく、止まりそうな人を止めない道具を作る。

## DAKEが作りたい未来

DAKEがあることで、誰かにとっての小さな障害が一つ減る。

質問する回数が一つ減る。
返事を待つ時間が一つ減る。
やり直す作業が一つ減る。
不安になる瞬間が一つ減る。

その積み重ねによって、現場全体が少し静かになる。

誰かが無理に助け続けなくても、仕事が自然に流れる。

詳しい人だけが仕事を進められるのではなく、誰でも自分の持ち場で役割を果たせる。

俺がDAKEで作りたいのは、そんな状態だ。

## 結論

DAKEは、仕事ができる人をさらに強くするためだけの道具ではない。

仕事をしたいのに、途中で止まりそうになっている人の側に置く道具である。

迷わない。
止まらない。
難しくない。
必要以上に増やさない。

人が止まる場所を見抜いて、先に道具と流れを置く。

その人が、自分の力で仕事を終えられるようにする。

それが、俺がDAKEを作る理由である。

## 基本原則

ツールを点で増やし、カテゴリで線を引き、用途別ページで面にする。

# 11. サープコンクエストの定義

DAKEが検索の面を広げる。

PEAKHEADZが活動を一つに束ねる。

菊田幸彦が、なぜ続けるのかを残す。

役に立つ道具を積み重ねた結果として、DAKE、PEAKHEADZ、菊田幸彦の名前と信頼がネット上に残る状態を作る。

検索エンジンを攻略するために道具を作るのではない。

人が止まる場所へ、本当に使える道具と流れを先に置く。

その結果として、検索の面を取る。
